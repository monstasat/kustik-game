# 🐌 Кустик: Путь к огурцу

Отдельная игра про улитку Кустика.

## Цель

Собрать 25 огурцов, пережить три Мусорные Катастрофы и добраться до Легендарного Огурца.

## Управление

- ⬆️ Прыжок — перепрыгивать препятствия
- 🐚 Спрятаться — пережидать атаки птиц
- 🛡 Сепия — защита от одного удара

## Боссы

Мусорный босс появляется после:

- 10-го огурца
- 18-го огурца
- 24-го огурца

После последнего босса появляется Легендарный Огурец.

> Мягкий. Сочный. Легко соскабливается радулой. Это была любовь.
